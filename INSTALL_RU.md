# Builder — быстрый запуск (RU)

## Установка

1. Установите **Godot 4.2+**, **Git** и **GitHub CLI**.
2. Клонируйте репозиторий `https://github.com/KIBHR/builder.git` и переключитесь на ветку `feature/godot-workspace-mvp`. Либо скачайте исходники из Pull Request #1.
3. Откройте `project.godot` в редакторе Godot и запустите проект клавишей **F5**.
4. Для доступа к GitHub выполните в терминале `gh auth login -h github.com` и при необходимости `gh auth setup-git`.

## ChatGPT внутри Builder

1. Создайте API-ключ в OpenAI Platform (оплата API отдельная от подписки ChatGPT).
2. В приложении откройте **ChatGPT · в Builder** и вставьте ключ в поле, затем нажмите **Подключить**. Ключ хранится **только в памяти**, не сохраняется в настройках.
3. Выберите доступную вашей организации модель и отправьте запрос. **Ctrl+Enter** на Windows/Linux или **Cmd+Enter** на macOS также отправляет сообщение.
4. Для анализа кода выберите проект в выпадающем списке и используйте кнопку **Добавить файл проекта…**. Выбранный файл отправится в OpenAI только вместе с вашим сообщением. Будьте внимательны: не отправляйте файлы с паролями и токенами.
5. **Новый чат** сбрасывает историю, **Отмена** прерывает выполняемый запрос, **Копировать ответ** копирует результат.

Встроенный чат — интерфейс к **OpenAI Responses API**, **не** веб-версия chatgpt.com. Он не использует сессии ChatGPT Plus/Pro и не загружает существующую историю бесед.

## Оконный и полноэкранный режим

Кнопка **На весь экран  F11** в верхней правой части Builder включает полноэкранный режим. Повторное нажатие кнопки или **F11** возвращает оконный режим и прежний размер окна.

**Ограничения MVP:** ещё нет готовых установочных пакетов, официальной встраиваемой веб-сессии ChatGPT, исполнения кода ассистентом или полноценной автоматизации GitHub через чат. До рабочего релиза необходимы проверки в Godot и ручные тесты на Windows/macOS/Linux.
